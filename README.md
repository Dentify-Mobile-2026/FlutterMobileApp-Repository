# Dentify · App móvil

Aplicación Flutter para el personal de consultorios dentales: inicio de sesión, pacientes e historias clínicas, citas, inventario, pagos y dashboard.

**Tecnología:** Flutter (Dart ^3.7), Riverpod, arquitectura por capas (data / domain / presentation).

## Ejecutar

```bash
flutter pub get
flutter run
flutter test
flutter analyze
```

La URL del backend está en `lib/core/network/api_constants.dart`.

Ver `NOTICE.md` para el origen del proyecto y los créditos.
